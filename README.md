# goit-algo2-hw-07

Домашнє завдання до теми «Алгоритми керування кешем».

## Завдання 1. Оптимізація запитів за допомогою LRU-кешу

У файлі `task1.py` реалізовано порівняння швидкості обробки запитів до великого масиву:

- без кешування;
- із використанням LRU-кешу.

Програма:

- створює масив із 100 000 випадкових чисел;
- генерує 50 000 запитів `Range` і `Update`;
- обчислює суму елементів у заданому діапазоні;
- оновлює значення елементів;
- видаляє з кешу діапазони, яких торкнулося оновлення;
- порівнює загальний час виконання;
- виводить коефіцієнт прискорення.

Запуск:

```bash
python3 task1.py
```

## Завдання 2. LRU Cache і Splay Tree

У файлі `task2.py` реалізовано два способи обчислення чисел Фібоначчі:

- `fibonacci_lru(n)` із використанням `@lru_cache`;
- `fibonacci_splay(n, tree)` із використанням Splay Tree.

Програма:

- обчислює числа Фібоначчі для значень від 0 до 950 із кроком 50;
- вимірює середній час виконання;
- виводить результати у вигляді таблиці;
- будує графік порівняння;
- формує текстовий висновок.

Запуск:

```bash
python3 task2.py
```

Після запуску створюється графік:

```text
fibonacci_comparison.png
```
